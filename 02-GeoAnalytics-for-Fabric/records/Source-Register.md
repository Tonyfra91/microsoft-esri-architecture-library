## Source Validation Rules

Architecture statements must be traceable to an authoritative source.

The preferred order of authority is:

1. Microsoft Learn
2. Esri Product Documentation
3. Jointly validated Microsoft + Esri content
4. Internal architecture reviews

---

## Exclusions

The following do not qualify as authoritative architecture sources:

- Marketing slides
- Conference presentations
- Customer decks
- Unvalidated architecture diagrams
- AI-generated content
